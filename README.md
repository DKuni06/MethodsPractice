# MethodsPractice
This .NET web app is a project to get practice with methods and learn more about how to commit and push to the Github platform and how to format README files.

## Prerequisites
- Download and install [Visual Studio 2026](https://visualstudio.microsoft.com/downloads/) with the .NET desktop workload
- [.NET 10 SDK] (https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- Windows OS
